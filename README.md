# AgentFlow

中文多智能体桌面工作台，支持 macOS 和 Windows。用可编辑的卡片流程组织已接通的本地 CLI 与自定义 API，查看逐次对话、任务状态和真实用量。

输入需求并选择启动模型 → 模型推荐当前可用团队 → 你确认流程 → 各环节执行 → 模型验收 → 你最终接受。每一步都可独立选择模型和它实际支持的思考强度。

## 下载与开始使用

1. 打开本仓库的 **Releases** 页面，按操作系统和处理器选择发布资产（macOS arm64/x64、Windows x64，以该版资产为准）。源码压缩包不包含可直接运行的桌面应用。
2. macOS：解压应用包，将 `AgentFlow.app` 放入“应用程序”。Windows：运行 `Setup.exe` 安装程序，或解压 ZIP 后打开 `AgentFlow.exe`，保留其相邻资源文件。
3. 打开“连接”，检测已安装的执行器，按需完成其官方登录或添加 API。只有已就绪的模型可参加自动执行。
4. 点击“新任务”，输入需求。可选择项目文件夹；未选择时，应用建立私有任务目录。发送后先检查推荐团队并确认，再开始执行。

发布资产的可用平台、架构和签名状态以对应 Release 说明为准。当前本地构建不提供 Apple Developer ID 公证或 Windows Authenticode 发布者签名；不要通过关闭系统安全功能来处理来源不明的安装包。

Enter 发送，Shift+Enter 换行。流程卡片可拖入、重排或移除，也提供键盘操作。等待中的环节可修改；进行中的调用保持原参数。任务可暂停、取消和重试。删除聊天会将记录移入系统回收站，项目目录和产物保留。

## 能连接哪些智能体

| 入口 | 接入方式与边界 |
| --- | --- |
| GPT / Codex、Claude Code | 通过各自官方 CLI 与授权入口；需要本机可用的执行文件、账号和模型权限。 |
| DeepSeek Harness | 使用已支持的 headless/连接器入口；保留具体提供方路由和模型标识。 |
| WorkBuddy、CodeBuddy | 优先关联 WorkBuddy 原有桌面授权，直接检查 CodeBuddy 官方 CLI 的已有会话；仅在确需授权时登录。缺少执行组件时显示待接入，CodeBuddy 登录地区由用户选择。 |
| Google Antigravity / Gemini | 识别桌面应用和官方 CLI；Antigravity 确认官方账号、目录及只读能力后启用；Gemini 复用已有官方配置，安全验证默认模型后启用。Google CLI 交互登录在系统终端完成，未验证的桌面登录保持待接入。 |
| OpenCode 及自动发现的应用 | 只有经过验证的执行适配器才能自动运行。仅发现应用或目录时保持待接入。 |
| 豆包、马维斯等 GUI 应用 | 可显示安装信息并打开原应用；缺少可靠任务执行及结果接口时不能加入自动执行。 |
| 自定义 API | 支持 OpenAI Chat Completions、Responses 和 Anthropic Messages 兼容协议；由用户配置服务与模型。 |

本地产品、模型目录、授权方式与平台支持会变化，以“连接”页实时检测为准。AgentFlow 不包含上述产品的订阅、账号或第三方运行时，也不承诺可以调度所有 GUI 智能体。[平台范围](docs/platform-support.md) · [授权边界](docs/authentication-v03.md)

API 保存只写本地；刷新目录会访问服务；“验证连接”会产生少量真实推理用量。API 文件工具限定在批准的工作区，规划与验收只读；API 适配器没有通用终端工具。费用由用户配置的服务收取。

## 对话与用量

每个启动推荐和流程环节都可打开“对话”，查看已保存的实际发送、公开回复、模型、思考强度、状态与重试。旧记录缺少输入时明确显示未记录；不从最终回复反推输入，也不展示模型隐藏思维。

用量页支持按模型选择近期调用、输入/输出/缓存/推理/费用指标、曲线与条形图，以及模型样本环图。悬停或键盘聚焦可查看调用详情。减少动态效果设置会关闭几何动画。

- **任务调用**：AgentFlow 已保存尝试的真实计量，macOS、Windows 均可用；执行器未提供的字段保持未知。
- **软件样本**：macOS 通过 TokenLens 同源 Swift 读取器读取受支持软件的本地日志，展示最近 7 天的限量样本。Windows 当前不提供这套 Swift 软件日志读取器，仅显示任务调用计量。
- 缓存读属于输入，推理属于输出，不能再次相加。环图默认仅统计输入与输出均已提供的样本；未知不当成零，样本不代表完整账单、订阅余额或官方额度。

## 开发与构建

需要 Node.js 22.12+ 和 npm。克隆仓库后运行：

```sh
npm ci
npm run check
npm test
npm start
```

`npm start` 启动开发版。开发测试可通过 `AGENTFLOW_DATA_DIR` 指定隔离数据目录，避免使用正式聊天记录；发布版不接受这一环境覆盖。

macOS 软件样本读取器需要 Xcode Command Line Tools 中的 Swift 编译器，并按目标架构构建。Windows 不需要 Swift。平台打包命令与 CI 产物说明见 [构建与发布](docs/build-release.md)。

## 数据与安全

聊天、对话、配置与私有工作区存于 Electron 的系统应用数据目录。API 密钥使用操作系统安全存储加密，界面只返回是否已设置；不随源码或发布资产提供任何账号数据。第三方 CLI 的账号仍由原厂组件管理。

渲染页面不开放 Node 或网络权限，主进程校验 IPC 来源。外部 CLI 仍具有它自身的工具、网络及文件权限；AgentFlow 不是整机沙箱。模型输出和项目文件都应作为不可信输入处理。安全问题请通过仓库提供的私密报告渠道反馈，勿在公开 Issue 粘贴密钥、完整对话或用户目录。[安全边界](docs/security-v03.md) · [测试范围](docs/validation-v04.md) · [发布审计](docs/release-audit.md)
