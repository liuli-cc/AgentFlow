# 测试与验收说明

测试结果以目标提交的 CI 日志和对应 Release 说明为准，不在文档中固化会随代码变化的测试数量。

## 自动回归

```sh
npm run check
npm test
```

Node 回归覆盖流程确认、模型与思考参数、任务重试和删除、API 三协议、文件工具与路径边界、认证、IPC、会话记录、敏感数据脱敏、日志增量与去重。测试使用合成账号、临时目录及受控服务；不要使用正式用户数据执行测试。

浏览器和 Electron 的专项开发检查还覆盖导航、卡片内部指针拖放、原生菜单焦点、Enter/IME、授权取消、窄窗口、减少动态效果、图表和对话查看。开发工作目录中的临时检查材料不随源码分发。

## 图表与计量

- 曲线逐采样点通过，按区间保形，缺失值断开，重复时间回退直线；不超出相邻端点取值范围。
- 主线与面积共同从左向右裁切，柱形底边固定并向上展开。同数据状态推送复用图表节点，不能打断动画；主动刷新、切换及真实数据改变重播。
- 环图按当前软件或任务范围分别统计；默认只统计输入与输出均已提供的调用。缓存、推理不重复计数，未知不补零，真实零值不变成假份额。
- 同名模型跨提供方分别计量，费用使用 USD 单位。软件样本限量，不代表全部账单。

## 对话与外部调用

对话检查包含实际输入、公开多条回复、具体尝试、响应模型、完整文本复制、旧输入缺失和异步关闭安全。只恢复能精确匹配来源的历史记录，不伪造未保存内容。

协议模拟器通过只证明适配器的协议行为；目录读取成功不证明所有模型可推理；一次真实调用不证明整个产品可调度。macOS 原生验收与 Windows CI 的证明范围分别保留，参阅 [桌面验收边界](native-validation.md)。
