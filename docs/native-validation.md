# 桌面平台验收范围

macOS 开发验收覆盖应用启动、原生菜单、目录选择对话框、卡片拖入与排序、移除、Enter/Shift+Enter、模型与思考档位选择、聊天删除、图表与逐环节对话查看。图表动效另外通过程序几何检查；减少动态效果与窄窗口布局有浏览器回归。

上述记录不包含个人桌面截图、账号身份或聊天内容，也不表示全部外部智能体均已认证。Windows 的 CI 构建与测试结果应以对应提交记录为准；构建成功不能替代 Windows 桌面交互与外部 CLI 兼容性验收。

签名、公证与处理器架构以具体 Release 资产说明为准。未进行发布者签名的包可能触发系统提示；不能把临时签名描述为已公证发行。
