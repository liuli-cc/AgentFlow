# 方案与安全设计依据

AgentFlow 是独立实现的本地桌面编排器，不是其他多智能体框架的 fork。通用 API agent 框架不能自动复用任意桌面产品的订阅、授权、工具权限与会话，因此当前以受支持的官方 CLI 和兼容 API 适配器为执行边界。

采用顺序状态机、持久尝试记录、两次人工确认和本地 IPC。界面可发现更多应用，但发现结果不能注入执行文件或冒充自动执行器。没有可靠执行及完成接口的 GUI 产品保持待接入。

模型目录、思考强度、工具能力和用量字段来自对应适配器，不用统一参数猜测所有提供方能力。未知值不补零，不通过静默替换模型来宣称成功。

早期方案调查与本机验收的个人记录不随公开源码分发。当前实现边界见 [安全说明](security-v03.md)，平台边界见 [平台支持](platform-support.md)。已知通告扫描和测试都不能证明软件不存在漏洞。
