# 平台支持范围

AgentFlow 的 Electron 界面、流程状态机、对话记录和自定义 API 为跨平台实现。发布资产只承诺对应 Release 明列的平台与架构；构建成功不等于所有本地厂商执行器均兼容该平台。

| 功能 | macOS | Windows |
| --- | --- | --- |
| 中文界面、流程编辑、两次人工确认、历史对话 | 支持 | 支持；以 CI 和该版验收为准 |
| OpenAI Chat、Responses、Anthropic 兼容 API | 支持 | 支持 |
| AgentFlow 本次任务的真实用量 | 支持，未知字段保留 | 支持，未知字段保留 |
| TokenLens 同源软件日志样本 | Swift helper；读取受支持本地日志 | 当前不提供，只显示任务计量 |
| 本机官方 CLI、桌面授权复用、应用发现 | 取决于已实现的适配器、安装和认证 | 取决于 Windows 适配器及实际检测，不能推定与 macOS 一致 |
| 未提供执行/完成接口的 GUI 智能体 | 发现或打开原应用；不可自动执行 | 同样不能靠安装或登录启用自动执行 |

macOS 软件日志读取器需要 Swift 工具链构建，最低系统要求还受 helper 编译目标与 Electron 版本约束。Windows 不运行这个 Mach-O helper，也不会把缺失的软件计量显示为零。

官方 CLI 和账号需用户自行安装及授权，不随 AgentFlow 发布。厂商更新、目录差异、账号套餐、网络或模型权限均可能影响连接；“连接”页状态比历史截图或开发机目录更可靠。
