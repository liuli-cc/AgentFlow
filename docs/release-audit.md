# 源码发布数据审计

审计范围为应用源码、文档、测试、锁文件和随包静态资源；不把依赖目录、开发工作目录或系统应用数据当作发布内容。

## 已清理与排除

- 历史文档中的个人工作目录、真实运行编号、原需求、回复原文、逐阶段调用数值及账号专属目录已删除或改成通用测试范围。
- 源码不附带用户配置、API 连接存储、聊天、逐次对话、原厂会话或自动创建的任务目录。
- `.gitignore` 排除依赖、打包产物、开发临时目录、运行时记录、环境文件和签名密钥。忽略规则不能清除已经提交的文件，发布前仍须检查 Git 暂存清单和历史。
- 合成密钥、测试身份与固定假路径仅用于安全边界回归，不对应真实账号。不要用真实凭据替换这些夹具。
- 作者署名、应用标识和第三方许可证属于项目元数据，保留。

对当前发布树进行凭据格式、本机路径、私网地址、敏感文件名与二进制字符串检查，未发现需要发布的真实凭据或用户会话。该结论是本次有限静态审计，不代替持续秘密扫描或人工复核。

## 发布前复核

检查实际加入版本库及归档的文件，确认没有意外包含系统应用数据、测试账号、缓存、日志、截图和签名材料。发布资产须从干净源码构建，按目标平台重新运行测试并说明签名与验收范围。禁止把完整会话或认证诊断作为公开发布日志。
