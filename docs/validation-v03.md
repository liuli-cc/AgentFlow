# 0.3 测试范围摘要

此阶段回归覆盖卡片拖入、邻近吸附、排序、移除、键盘后备、拖动中刷新保持源节点、原生菜单焦点、Enter/Shift+Enter/输入法确认、任务删除及产物保留。

API 测试使用三种协议的本机 HTTP 模拟器，检查文件工具、参数传输、取消、认证错误和人工确认；合成密钥不代表任何外部付费服务已配置。授权测试检查官方入口、地区区分、取消、超时和认证元数据边界，不把账号状态当作模型调用成功。

macOS 原生窗口交互与隔离 Electron 程序测试曾分别执行。Windows 兼容性不能由这些 macOS 结果推定。个人账号、具体模型目录、浏览器过程、暂停聊天与工作目录不包含在公开记录中。
