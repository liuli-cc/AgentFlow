# 状态、API 与工作区边界

- 启动推荐后必须显式确认流程；模型验收后必须由人最终接受。兼容入口不绕过确认。
- 提供方、模型及思考强度必须来自已声明的可用能力；未知应用不能通过发现描述覆盖已知执行器。
- 已批准的工作区与后续读写都检查真实路径，拒绝路径穿越及符号链接逃逸。API 规划和验收只读，API 文件工具不提供通用终端执行。
- API 地址默认要求 HTTPS，本机回环可用 HTTP；拒绝 URL 内账号、查询和片段，不跟随带授权请求的重定向。请求有取消、超时、响应大小及工具循环上限。
- API 密钥经系统安全存储加密；状态只回传 hasKey。错误与文本按已知密钥及常见凭据格式脱敏，缺少计量保持未知。
- 不同任务保存独立尝试记录；重试保留此前实际用量，不因新事件缺字段覆盖已记录指标。同目录任务需要调度，不能以并行调用交叉修改同一项目。

继续参阅 [当前安全说明](security-v03.md)。测试结果应以当前提交的 CI 为准，历史扫描结果不能代表新版本仍然没有已知通告。
