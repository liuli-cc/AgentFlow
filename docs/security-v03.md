# 安全边界与报告

## 当前防护

- Renderer 不开放 Node、网络、内联脚本或 eval；IPC 校验实际窗口、主 frame 与本地页面来源，调用参数再次在主进程校验。
- 子进程使用固定执行入口、独立参数和受限环境，不拼装 shell 命令。登录动作使用官方命令或协议，取消和超时清理本应用启动的进程。
- 未就绪入口不能借旧交接状态绕过自动执行检查；确认、调度、恢复、重试和参数更新均检查可用性。
- 探针结果绑定具体入口、模型及有效状态；API 正式调用认证失效后撤销可用状态。目录不等于逐模型验证。
- 用户数据存于系统应用数据目录。私有文件采用限制权限及原子写入；API 密钥经系统安全存储加密。任务对话按已知记录标识读取，不接受任意文件路径。
- 长文本复制由主进程从已知记录提取。公开状态和认证错误不返回账号凭据、原始认证诊断或完整授权响应。
- 删除聊天只处理记录，保留工作目录及产物；正在执行的聊天需要先取消。

API、状态及路径防护另见 [工作区边界](security-v02.md)，授权细节见 [授权说明](authentication-v03.md)。

## 仍然存在的信任边界

外部 CLI 有自身的文件、网络和工具权限，AgentFlow 不提供整机沙箱。模型、项目文件及服务响应都是不可信输入。自定义 API 由用户选择，发送内容与费用受对应服务条款约束。

安全存储可用性由操作系统和运行环境决定；无法提供受支持的安全存储时不应降级保存明文密钥。源码与发布资产不包含用户的账号或执行器运行时。

测试、依赖审计及已知通告查询不等于安全认证，也不能证明不存在未知漏洞。构建、依赖与平台发生变化时需要重新验证。

## 报告问题

优先使用仓库的私密漏洞报告功能；未启用时先通过维护者提供的私密渠道联系。公开 Issue 仅描述不含秘密的复现步骤，勿附密钥、授权链接、原始会话、完整用户目录或个人截图。复现材料使用合成数据与临时工作区。
